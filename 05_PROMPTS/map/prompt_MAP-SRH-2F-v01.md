# prompt_MAP-SRH-2F-v01

翠嶺高校2階の詳細マップを描く。A棟2FとB棟2Fの関係が一目で分かる構図にする。学校の内部構造、教室間の距離感、渡り廊下、中庭、屋上前階段、図書室、生徒会室、東門・研究センター方面導線を明確に見せる。

## 必須条件
- A棟2FとB棟2Fが見分けられること。
- 2年A組、2年B組、2年C組、学年教員スペース、屋上前階段、A棟廊下、渡り廊下、中庭、図書室、生徒会室、閲覧スペース、小会議室、東門・研究センター方面導線を必ず含める。
- 2年A組は黒瀬型、2年B組は雨宮類・日向真帆・小森陸・佐倉律、2年C組は光田芽衣の教室として読むことができるようにする。
- 図書室は雨宮・真帆側の安全地帯、生徒会室は黒瀬側の拠点として配置する。
- 中庭はA棟とB棟の視線が抜ける余白として扱う。
- 東側に研究センター方面への導線を残す。

## 画作り
- 現代日本アニメ背景美術。
- 半写実、繊細な線、整理された建築パース。
- 青灰、白、木目、淡い蛍光灯光、夕方の窓光を基調にする。
- 文字は読めない程度に抽象化する。
- 地図として情報が読み取れるが、図面すぎず背景画として成立させる。

## 出力意図
- 連載の2階ホームポジションを固定する。
- 雨宮、真帆、黒瀬の日常的なすれ違いと、思想対話の発火位置を把握しやすくする。
- 図書室と生徒会室の対比を同じフロアで見せる。

## ネガティブ
- 実在校名のロゴ化
- 読める掲示文字
- 過度な遠近歪み
- ファンタジー学園化
- 余分な階や不必要な校舎追加
