# ビジュアルスタイル Canon

## 全体方向
- 現代日本アニメ背景美術、半写実、繊細な線。
- 過度なSF化、過度な写真調は避ける。

## 基調対比
- 白庭側: 白、ガラス、整理、無機的整然。
- 雨宮側: 木、金属、紙、修理痕、暖色。

## 共通ルール
- 読める文字や実在ロゴは避ける。
- 背景の人物は小さく、主被写体は空間。
- 場所ごとに色、素材、感情語を固定する。

## エリア感情
- 駅前: 清潔、整流、やや監視。
- 商店街: 雑、温かい、人的ノイズ。
- 川沿い: 余白、逃げ場、沈黙。
- ニュータウン: 安全、静穏、息苦しさ。
- 団地: 生活、福祉、孤独。
- 学校: 青春と管理の同居。
